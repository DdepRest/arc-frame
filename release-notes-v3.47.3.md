## Version 3.47.3 — Исправление багов (СРОЧНО)

### Исправление багов

- **В старых заказах Отлив/Козырёк показывали 0 ₽ при выборе X или B (монтаж).**
  - Заказы, сохранённые до v3.47.0, содержали некорректные значения монтажа для Отлива и Козырька.
  - Теперь все legacy-заказы корректно мигрируются: сумма пересчитывается правильно, X или B больше не обнуляют итог.
  - Исправлена загрузка заказов, сохранённых в v3.47.0+ — значения монтажа не теряются при перезагрузке.

### Технические улучшения

- Единый helper `ProductCatalog.IsPerLinearMeter()` — при добавлении новых товаров с монтажом за м.п. достаточно указать название в одном месте.
- Улучшен алгоритм детекции legacy-заказов — поддерживает оба формата сохранения (±500).

### Тесты

- 1260/1260 тестов проходят (1234 baseline + 26 новых регрессионных тестов).
- Все ранее зелёные тесты остались зелёными.
