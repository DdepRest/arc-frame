# freebuff-ru — русская локализация Freebuff Desktop

Неофициальный патч перевода интерфейса Freebuff Desktop на русский язык.
Правятся только текстовые строки в UI-бандле установленного приложения;
логика не изменяется.

## Файлы

- `ru.py` — словарь переводов:
  - `RU_BY_INDEX` — строки из UI-контекстов (children/label/tooltip/…), ключ — индекс в `candidates_indexed.txt`;
  - `RU_BARE` — «голые» строковые литералы (тернарники, статусы, массивы), применяются с проверкой на сравнения в коде.
- `candidates_indexed.txt` — эталонный список кандидатов (raw-литерал + отображаемый вид), снят с бандла при создании словаря.
- `apply.py` — применяет словарь:
  - index-проход идемпотентен: сверяет raw-литерал из `candidates_indexed.txt` с текущим файлом (уже переведённые пропускаются);
  - bare-проход пропускает строки, участвующие в сравнениях/`value:`/`.includes()` в коде;
  - делает резервную копию `.bak-ru2` (первый запуск);
  - `--auto` — режим для планировщика: пишет лог в `apply.log` (работает и под `pythonw.exe`, где нет консоли), не трогает файлы, если всё уже переведено, и в конце отчитывается об оставшихся английских UI-строках.
- `task.xml` — описание задачи планировщика Windows «Freebuff RU translate» (вход в систему + повтор каждые 30 минут).

## Использование

```bash
cd freebuff-ru
python apply.py --auto   # применить + лог в apply.log (режим планировщика)
python apply.py          # применить (с резервной копией и отчётом)
python apply.py --dry-run  # ничего не менять, показать вхождения коротких слов
```

Применяется к `%LOCALAPPDATA%\Programs\@codebufffreebuff-desktop\resources\orchestrator\ui\assets\index-*.js`
(имя бандла меняется при обновлениях — скрипт сам находит файл по маске `index-*.js`).

## Автоприменение при обновлениях

Установлена задача планировщика **«Freebuff RU translate»**: запускает
`apply.py --auto` при входе в систему и каждые 30 минут. После обновления
приложения перевод восстанавливается автоматически (в течение получаса
или при следующем входе), даже если Freebuff перезаписал бандл.

Ход выполнения — в `freebuff-ru/apply.log`: видно, что переведено,
и какие английские строки остались (новые строки новых версий попадут
в отчёт `leftover English UI strings` — их потом надо добавить в `ru.py`).

Управление задачей:

```cmd
schtasks /query /tn "Freebuff RU translate"      :: статус
schtasks /run /tn "Freebuff RU translate"        :: запустить сейчас
schtasks /delete /tn "Freebuff RU translate" /f  :: удалить
```

## После обновления приложения

Обновление Freebuff перезаписывает бандл; задача планировщика вернёт
перевод автоматически. Если в `apply.log` появились новые `leftover`-строки
(текст интерфейса новой версии), их нужно добавить в `ru.py` — сказать
об этом агенту, и он дополнит словарь.

## Откат

В папке бандла лежат резервные копии:
- `index-*.js.bak-ru` — оригинал (до всех правок);
- `index-*.js.bak-ru2` — после первого прохода (миссия + 271 строка);
- `index-*.js.bak-ru3` — промежуточная.

Для полного отката: скопировать `.bak-ru` поверх `index-*.js` и перезапустить приложение.

## Что намеренно не переводится

Названия моделей (Fable 5, Opus, Sonnet, GPT-5.6-*), имена тем редактора
и языков подсветки, имена инструментов агента (Edit/Write/Read/…), SVG-пути,
команды (`bun install`), строки с кавычками-типографикой («» — используются
как значения HTML-entity в коде библиотеки).
