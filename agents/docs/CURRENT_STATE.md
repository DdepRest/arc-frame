Когда менеджер просит добавить товар с монтажным переключателем (Anwis, На навесах, Дверная сетка, Оконная на метал. крепл., Отлив, Козырёк), но не называет монтаж, AI больше не выполняет действие с молчаливым дефолтом («Без монтажа» для Отлива/Козырька, «Монтаж включён» для сеток): `AiClarificationForm.ShouldAskForMissingParams` + `InstallationModeSpecified` требуют явного монтажа и открывают предзаполненную карточку «Не указан монтаж — выберите вариант в карточке ниже». На «отлив бел 170 900» карточка приходит с Отлив + Белый + 170×900, монтаж выбирает пользователь. `DetectInstallationMode` распознаёт «с монтажом» → 0 / «без монтажа» → 1 / «в конструкцию» → 2 и предзаполняет карточку; товары без монтажа (Короб, ПСУЛ, ручные) не затронуты.
